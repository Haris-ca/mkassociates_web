# mkassociates_web

Welcome to the official repository for **MK Associates**. This project contains the source code for the company's web presence, designed to showcase services, portfolios, and contact information cleanly and professionally.

---

## 🚀 Features

* **Responsive Design:** Optimized for mobile, tablet, and desktop viewports.
* **Modern UI/UX:** Clean layout built for professional presentation and fast load times.
* **Automated CI/CD:** Continuous deployment configured to push updates directly to an AWS EC2 instance on every push to main.
